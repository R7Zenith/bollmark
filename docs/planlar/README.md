# Planlar

Her dosya tek bir özelliğin ya da düzeltmenin planıdır. Bu klasörde yalnız
**açık** planlar durur; biten ya da vazgeçilen planlar `arsiv/` altındadır.

Kod yorumlarındaki `bkz. X_PLANI.md` atıfları dosya adıyla verilmiştir; dosyayı
önce burada, yoksa `arsiv/` altında ara.

## Kural

- Yeni planın ilk satırlarına durum yaz: `Durum: bekliyor` / `devam ediyor` /
  `uygulandı (tarih)` / `iptal`.
- Plan bitince dosyayı `arsiv/` altına taşı, aşağıdaki tablodan ve
  kökteki `DEPLOY_STATUS.md` "Açık işler" tablosundan satırını sil.
